# Maden Tesisinde Demir ve Silika Oranı Tahmin Projesi

Bu proje, bir maden zenginleştirme (flotasyon) tesisinden alınan sensör verilerini kullanarak, nihai üründeki Demir (Fe) ve Silika (SiO2) oranlarını tahmin etmek amacıyla geliştirilmiş bir yapay zeka çalışmasıdır.

## Kullanılan Teknolojiler
* Python
* Pandas & NumPy (Veri Analizi ve Manipülasyonu)
* Scikit-Learn (Yapay Zeka / Makine Öğrenmesi)
* Matplotlib (Grafiksel Görselleştirme)

## İstatistik, Model Başarısı ve Algoritma
Projede, tesisteki karmaşık ve doğrusal olmayan fiziksel/kimyasal ilişkileri çözmek adına Random Forest Regressor (Rastgele Orman) algoritması kullanılmıştır. Eğitilen yapay zeka modeli, test verileri üzerinde %90'ın üzerinde bir tahmin başarısı (R2 Skoru) yakalamıştır.
